# AI Architecture Portfolio

A portfolio documenting an AI system architecture from initial framing to a final capstone.

## Scenario

To be defined in [Session 01: Framing](docs/01-framing.md). Describe the problem, intended users, desired outcomes, and constraints before choosing an architecture.

## Assumptions

- The scenario, requirements, and technology choices are not yet finalized.
- Each session has its own Markdown file in `docs/`, numbered in reading order.
- Significant architecture decisions are recorded in `adr/`, including alternatives and consequences.
- Diagram source files are kept alongside exported PNG or SVG files in `diagrams/`.
- The final architecture PDF and presentation slides belong in `capstone/`.

## How to read this repo

1. Start with the numbered session notes in `docs/`.
2. Review the supporting diagrams in `diagrams/`.
3. Read the architecture decision records in `adr/` for the reasoning behind choices.
4. Use `capstone/` for the final architecture and presentation once completed.

```text
ai-architecture-portfolio/
├── README.md
├── docs/
│   ├── 01-framing.md
│   └── 02-building-blocks.md
├── diagrams/
├── adr/
│   └── 0001-model-hosting.md
└── capstone/
```
